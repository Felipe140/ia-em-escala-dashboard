# IA em escala

Painel autocontido para explorar dados públicos sobre adoção de IA generativa ao longo do tempo.

Abra `index.html` diretamente no navegador. O painel funciona sem servidor, sem dependências externas e sem telemetria. Edições ficam somente no armazenamento local do navegador e podem ser exportadas ou apagadas pela própria interface.

Esta cópia está em revisão privada e traz `noindex` até que uma publicação pública seja autorizada separadamente.
